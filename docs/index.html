Task-first Markdown

Checkboxes are polished for actual daily use: quick toggling, completed-task hiding, progress counts, and readable light/dark states.

Notch-native rhythm

Open by hover or click, pin when you need it, and resize the panel while keeping it centered below the notch.

Local by default

Notebook JSON and PNG attachments live in Application Support. No account, no sync service, no server copy of your notes.
